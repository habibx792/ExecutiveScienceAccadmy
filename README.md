# Executive Science Academy

**Executive Science Academy** is an academic management system designed to handle the core operations of an educational institute in a clean, structured, and automated way.  
The project focuses on managing students, attendance, examinations, results, and fee collection with accuracy and transparency.

---

## Project Overview

Educational institutes are complex systems: students enroll, attend classes, take exams, and receive results while administrative processes run in parallel.  
This project brings all of that into a single, well-organized software solution.

The goal is simple:  
**less paperwork, fewer errors, and better visibility for everyone involved.**

---

## Main Features

### Student Management
- Student registration and profile management  
- Admission requests and approvals  
- Class and section allocation  
- Academic history tracking  

### Attendance Management
- Daily attendance marking  
- Monthly and yearly attendance reports  
- Student-wise and class-wise attendance records  
- Absence summaries  

### Examination & Results
- Exam creation and scheduling  
- Subject-wise marks entry  
- Automatic result calculation  
- Grade generation  
- Printable result cards  

### Fee Management
- Fee structure definition  
- Fee collection records  
- Pending and overdue fee tracking  
- Receipt generation  
- Financial summaries  

### Requests System
- Leave requests  
- Fee concession requests  
- Administrative approval workflow  
- Request status tracking  

---

## User Roles

- **Administrator**  
  Manages users, data, reports, and system settings.

- **Teacher**  
  Marks attendance, enters exam results, and reviews student performance.

- **Student**  
  Views attendance, results, fee status, and submits requests.
